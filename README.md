# research-vault
面向科研学习的本地文献、笔记与 AI 知识库

现阶段已实现 arXiv 和 OpenAlex 文献检索、PDF 入库，以及工作空间文献列表、PDF 阅读、本地 Markdown 笔记和选区批注。

应用需要登录。每个账号分别记住打开过的目录和当前工作空间。同一台电脑上的不同账号可以打开同一目录，并按操作系统权限读写同一份 PDF 和 Markdown。本机登记库现为 v3，工作空间文献库为 v5。位置、备份与迁移说明见 [数据库说明](backend/DATABASE.md)。更新后需重启 Python 服务。

工作空间现已统一：在文献阅读页打开一个本地目录，首页与各页侧栏都使用该空间。对话保存在空间的 `.lexivault/library.sqlite` 中；新空间不生成示例论文、示例对话或示例计划。研究计划与阅读笔记都是普通 Markdown，可以放在任意自己创建的文件夹中；知识库管理和研究计划页提供真实文件树。新空间不自动导入旧浏览器内容。详见 [工作空间说明](backend/WORKSPACE.md)。

## 启动文献阅读

在项目根目录运行（当前已安装本机依赖）：

```powershell
backend\.venv\Scripts\python -m backend
```

打开 <http://127.0.0.1:8000/index.html> 注册、登录。首次注册前请配置 [SMTP 发信](backend/DATABASE.md#邮件验证码)。关闭服务窗口即可停止。

首次在另一台机器准备环境（已在 Python 3.12 验证）：

```powershell
python -m venv backend/.venv
backend\.venv\Scripts\python -m pip install -r backend/requirements-lock.txt
backend\.venv\Scripts\python -m backend
```

若 8000 端口已被前端预览占用，请停止原预览或加 `--port 8001`。阅读功能需由 Python 服务同时提供页面和接口；只运行前端 `npm start` 不会提供本地笔记接口。

## 第一次使用

先注册账号，再登录进入首页。通过“选择工作空间 → 打开工作空间”选择已有目录。成功打开后，目录会出现在当前账号的最近列表中。其他账号登录后也可以主动选择同一目录。

账号和打开记录保存在本机。复制笔记和附件到另一台电脑时，保留目录结构即可在支持 Markdown 的编辑器中查看。

1. 在全局侧栏的工作空间菜单中选择“打开工作空间”，通过系统目录选择窗口打开磁盘上的已有目录；也可新建空间或切换已登记的空间。打开前会检查当前未保存内容，取消选择会保留当前空间。
2. 在侧栏点“新建工作空间”，输入名称并点“选择保存位置”。系统会在所选位置下新建同名文件夹，然后打开它。例如选择 `D:\科研资料`，名称填“毕业课题”，就会创建 `D:\科研资料\毕业课题`。
3. 在左侧展开实际文件夹，点击 PDF，在中间阅读、右侧记录笔记。同一页内选中文字后点「添加批注」，右侧会插入编号和摘录。点编号可回到原文选区。左栏右上角可导入 PDF；窄屏使用“论文目录／论文原文／阅读笔记”切换。
4. 右侧显示“已保存到本地”后，可在其他编辑器中打开对应 Markdown 文件。外部修改会自动更新；存在未保存草稿时会提示冲突。

新工作空间只生成 `.lexivault/` 内部目录，用于数据库、缓存和历史。文件删除使用电脑系统回收站，恢复到原位置后自动识别；应用内不再设置回收站入口。通过研究计划页或知识库管理页新建文件夹和笔记，导入 PDF 时选择目录；阅读笔记在首次保存时创建，也可关联已有 Markdown。工作空间不应放在代码仓库中。

### 从 arXiv 获取论文

登录后打开「文献发现」，输入关键词、标题或 arXiv 编号。检索使用公开接口，无需 API Key。把论文加入获取队列，选择当前工作空间内已有的目录，再点「开始获取」。PDF 保存后可直接点「打开阅读」。全文暂不可用时，可以保留题录并重试，也可以从来源正常下载后手动导入。队列逐篇处理时请保持页面打开。

### 从 OpenAlex 获取论文

打开「文献发现 → 来源与凭据」，选 OpenAlex，首次填入 [OpenAlex 账号设置](https://openalex.org/settings/api-key) 中的免费 API Key，再点「应用来源」。后端加密保存到当前账号，刷新或重新登录后继续使用自己的额度。同一入口可更换或移除 Key。部署配置见 [凭据主密钥说明](backend/DATABASE.md#openalex-个人凭据)。获取时先试公开 PDF，失败后尝试 OpenAlex 缓存，两处均不可用时保留题录和来源。

可直接指定目录：

```powershell
backend\.venv\Scripts\python -m backend --workspace "D:\ResearchLibraries\我的课题"
```

详细的保存规则、接口、测试和限制见 [backend/README.md](backend/README.md)。前端源码与构建说明见 [frontend/README.md](frontend/README.md)。
